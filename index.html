Hvem ser hva

Klinikken har to slags brukere.

En ansatt ser sin egen kalender og sine egne pasienter. En administrator ser alt, og er den som bestemmer hvem som får tilgang til hva.

Journalen har én regel til. Hver gang noen åpner et pasientnotat, skrives det ned hvem det var og når.

Bytt mellom rollene inne i panelet og se hva som forsvinner fra menyen.

I adminpanelet

Kalender

Dag, uke og behandler. Flytt, avlys eller opprett timer direkte i rutenettet.

Bestillinger

Søk, filtrering, paginering og fargebar per behandler. Ufordelte gruppetimer skilles ut.

Kunder og journal

Kundekort med historikk. Journalnotater krever registrert samtykke, og hvert oppslag logges.

Tjenester og behandlere

Pris, varighet og synlighet per tjeneste. Behandlere deaktiveres, aldri slettes.

Meldinger og venteliste

Innboks fra kontaktskjemaet, og en FIFO-kø som kan tildeles ledige timer.

Audit-logg

Hvem gjorde hva, når. Kun synlig for admin, og kan ikke redigeres av noen.

Nettsiden er bygget i ren HTML, CSS og JavaScript, uten rammeverk. Data ligger i en database hos Supabase, der hver bruker bare ser det rollen gir tilgang til. Siden finnes på norsk og engelsk, og ansatte kan legge den til på mobilen som en app.

Teknisk detalj

Statisk frontend uten byggesteg. Supabase i bunn: PostgreSQL med Row-Level Security, Auth, Edge Functions og pg_cron for planlagte jobber. To språk via JSON-filer, og et PWA-skall for de ansatte.
